# Smart Food Waste & Freshness Analyzer

## Project Overview
The Smart Food Waste & Freshness Analyzer is an R programming project designed to analyze food-related data, summarize food quantities and categories, and visualize freshness information.

## Objectives
- Analyze food waste-related data using R.
- Calculate basic statistical summaries.
- Categorize food records based on available dataset information.
- Generate graphs for data visualization.
- Demonstrate data analysis using RStudio and CSV datasets.

## Technologies Used
- R Programming
- RStudio
- CSV Dataset
- Data Visualization

## Project Files
- `food_analyzer.R` — R source code.
- `Food_Waste.csv` — Dataset used for analysis.
- `Smart Food Waste Analyzer.Rproj` — RStudio project file.

## How to Run
1. Download or clone this repository.
2. Open the `.Rproj` file in RStudio.
3. Ensure `Food_Waste.csv` is in the project folder.
4. Open and run `food_analyzer.R`.
